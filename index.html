AI-Augmented Delivery Case Study — Cheetah Squad PPP

A case study in delivering faster with AI while keeping full control — using Cheetah Squad PPP, a predictive cycling performance platform (Apr 2026 – Present), as the vehicle.

AcceleratorsA repeatable loop where AI accelerates each stage and a human owns the gate between them: Research (AI surfaces the critical concepts, evidence and trends → human confirms relevance and sets the business outcome per spec) → Analysis & Design (AI drafts business analysis and solution/algorithm design → human pressure-tests for accuracy) → Build & Test (AI builds and tests → human validates the results) → Deploy.
MethodologySpec-driven delivery: a canonical ARCHITECTURE document is the single source of truth and change gate, with a To Do document holding scope, used to plan each increment and sprint. No change ships without an ARCHITECTURE-and-scope diff in the same pull request — keeping work small, sequenced and traceable.
GovernanceHuman-in-the-loop as the control, not a step: senior judgement owns and signs off every decision. AI output is validated by a 45+ test automated safety harness before release and kept citation-anchored, so every contribution is traceable and auditable.
ToolsClaude Opus (reasoning, architecture, code review) and Gemini Pro (research), with explicit model routing for cost and task fit; GitHub Codespaces with version-controlled repos and sprint-based PRs; Python / Streamlit; MotherDuck (cloud DuckDB); Google Cloud for authentication.
OutcomesDesigned, built and shipped solo to a working MVP in six weeks — more iterations per sprint and change requests absorbed within baseline, with the method proving directly transferable to regulated enterprise delivery. Available to demonstrate on request.
